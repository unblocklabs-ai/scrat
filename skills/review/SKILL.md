# Review

Assess the supplied issue or pull request using the task context and relevant repository code.
Explain whether the reported concern is valid or the proposed change is correct, with evidence for actionable findings.
Keep the review focused on the task; do not modify repository files.

## Result

Return a concise assessment, findings with relevant file references, and any unresolved questions or limitations.
Scrat handles publishing the result to GitHub.
